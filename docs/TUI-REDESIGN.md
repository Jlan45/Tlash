# TUI 改版方案：lazydocker 式操作

> 状态：**已实现**（4 个问题均按方案确认）　·　日期：2026-11-11

## 1. 现状的问题

现在是“左侧导航 + 整页切换”：一次只能看一页，看节点时看不到连接和日志；每页快捷键各不相同，要按 `?` 才知道能做什么；表单和确认框会把整个内容区替换掉。

## 2. lazydocker 的核心操作模型

- **左侧一列堆叠的面板**（Project / Services / Containers / Images …），每个面板是一个列表，同时可见
- **右侧主面板**显示“左侧当前选中项”的详情，主面板内有多个标签页（Logs / Stats / Env / Config / Top），用 `[` `]` 切换
- 焦点在左侧面板之间移动：`←` `→` / `h` `l` / `Tab`，或数字键直达；`j` `k` 在列表内移动
- `Enter` 把焦点移进主面板（可滚动、可操作），`Esc` 返回
- 每个面板都用同一套单字母动作（`d` 删除、`s` 停止、`r` 重启 …）；`x` 弹出当前面板的全部动作菜单，菜单里也能直接执行
- `/` 过滤当前列表；`+` / `_` 切换屏幕模式（普通 / 主面板占一半 / 主面板全屏）
- 底部一行显示当前焦点可用的按键；确认框、输入框都是浮在界面上的弹窗
- 支持鼠标：点击面板获得焦点、点击条目选中、滚轮滚动

## 4. 面板与主面板标签

| 面板 | 列表内容 | 主面板标签 | 面板动作 |
|---|---|---|---|
| **1 状态** | 内核状态摘要（一项） | **概览**（速率曲线、端口、内存）· **日志**（实时日志）· **运行配置**（生成的 config.yaml） | `s` 启动/停止 · `r` 重启 · `m` 切换出站模式 · `i` 出口 IP |
| **2 订阅** | 订阅列表（流量、到期） | **信息**（链接、UA、流量、到期）· **内容**（原始 YAML） | `space` 启用 · `a` 添加 · `u` 更新 · `U` 全部更新 · `e` 编辑 · `d` 删除 · `i` 导入本地 |
| **3 代理组** | 代理组（当前节点） | **节点**（成员 + 延迟；`Enter` 进入后可选节点、单测）· **信息** | `t` 整组测速 · `T` 全部测速 · `o` 排序 · `u` 取消固定 · `P` 更新代理集 |
| **4 覆写** | 覆写列表 | **内容** · **最终配置预览** | `space` 启用/停用 · `a` 新建 · `e` 编辑 · `d` 删除 · `J`/`K` 排序 · `s` 作用范围 · `B` 回退配置 |
| **5 连接** | 连接（主机 + 速率） | **详情**（链路、规则、进程、流量） | `d` 关闭 · `D` 全部关闭 · `o` 排序 · `space` 暂停 |
| **6 规则** | 规则（类型、内容、目标） | **详情** · **规则集**（`Enter` 进入后可更新） | `space` 临时停用/启用 · `U` 更新全部规则集 |
| **7 设置** | 分类：内核 / 接管 / DNS / 嗅探 / 资源 / 定时任务 / 环境变量 / 工具 | 该分类的设置项（`Enter` 进入后逐项修改） | 分类自带的动作（如内核分类的 `D` 下载、`b` 回滚） |

外部内核模式（`--controller`）只显示 1 状态、3 代理组、5 连接、6 规则、7 设置（仅“工具”分类）。

## 5. 全局按键

| 按键 | 作用 |
|---|---|
| `←` `→` / `h` `l` / `Tab` `Shift+Tab` | 在左侧面板之间切换焦点 |
| `1`–`7` | 直接聚焦对应面板 |
| `j` `k` / `↑` `↓`，`PgUp` `PgDn`，`g` `G` | 列表内移动 / 翻页 / 首尾 |
| `[` `]`（主面板内也可用 `←` `→` / `h` `l`） | 切换主面板标签 |
| `Enter` / `Esc` | 进入主面板 / 返回左侧 |
| `/` | 过滤当前列表 |
| `x` | 弹出当前面板的动作菜单（可直接选择执行） |
| `+` / `_` | 屏幕模式：普通 → 主面板占一半 → 主面板全屏 |
| `?` | 全部快捷键 |
| `q` / `Ctrl+C` | 退出（不影响内核） |

动作字母在各面板间保持同一含义：`a` 添加 · `d` 删除/关闭 · `e` 编辑 · `u` 更新 · `space` 启用/切换 · `s` 启停或作用范围（只在不冲突的面板）。

## 6. 弹窗

确认框、表单、动作菜单都改为浮在界面中央的弹窗，背景保持可见。`Enter` 确认，`Esc` 取消。

## 7. 实现方式

- 只重写 `internal/tui` 的外壳和展示层；workspace、API 客户端、订阅、覆写、配置生成等下层模块不动
- 现有页面的数据获取、后台任务、表单、接管设置编辑器等逻辑都复用，按“面板列表 + 主面板标签 + 动作表”重新组织
- 每个面板的动作定义成一张表，同时驱动按键处理、底部提示、`x` 菜单和 `?` 帮助，保证三者永远一致
- 现有的端到端测试（真实 mihomo）改为按新按键操作，覆盖范围不缩小

## 8. 已确认

面板划分、内核设置放入“设置 → 内核”、窄终端自动全屏、日志作为“状态”面板的标签，均按本方案实施。
